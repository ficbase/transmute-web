通过 GitHub 联系维护者

网站由 ficbase 组织维护。当前公开联系渠道是项目的 GitHub Issues。可以先搜索已有问题，或登录 GitHub 后提交新问题。

反馈转换问题时可以提供什么？

  • 转换方向：TXT 转 EPUB，还是 EPUB 转 TXT。
  • 浏览器名称与版本、设备系统，以及文件的大致大小。
  • 页面显示的错误提示，或你预期的结果与实际结果。
  • 如涉及章节检测或乱码，提供一小段你有权公开的示例文字和已知编码。

GitHub Issues 是公开的。请不要上传私人文稿、完整受版权保护的书籍、账号信息或包含个人信息的截图。通常可以用自己编写的几行测试文字复现问题。

隐私、内容和改进建议

有关隐私说明、站内内容或功能改进的问题，也可以通过同一渠道联系。提交 Issue 后，维护者可在讨论中进一步确认情况；本站未承诺固定的响应时间。
