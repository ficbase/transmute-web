文件和书籍信息

你选择的 TXT、EPUB 和封面图片在浏览器中读取和转换。网站代码没有将文件内容、书名、作者或其他填写的书籍信息发送给网站服务器，也没有建立用于保存这些内容的在线账号或文件库。

转换结果保存在浏览器内存中，点击下载后写入你设备的下载位置。网站代码不通过 Cookie、localStorage 或 IndexedDB 持久保存所选文件。离开或关闭页面后，需要重新选择文件；下载文件的保留和删除由你管理。

访问请求和托管服务

本地转换不等于没有任何网络访问。打开网页和下载 WebAssembly 模块时，托管服务会收到常规请求，其中可能包含 IP 地址、请求时间、浏览器信息、访问路径和来源信息。

现有公开网站通过 GitHub Pages 提供页面服务，相关处理见 GitHub 隐私声明。如果你访问的是后续部署在 Cloudflare 上的版本，托管服务的数据处理见 Cloudflare 隐私政策。这些访问数据与本地读取的书籍内容是不同的数据。

Cookie、统计和广告

当前版本没有主动加载第三方统计或广告脚本，网站自身不设置广告 Cookie。AdSense 所有权验证元标签和 ads.txt 文件（如已配置）用于验证网站和发布商关系，不会自行展示广告或设置广告 Cookie。

如果未来启用 Google AdSense，我们会在启用前更新这份说明，列明实际广告服务和设置。Google 及其他第三方广告服务商可能使用 Cookie，根据你访问本站或其他网站的记录投放广告；Google 的广告 Cookie 可以让 Google 及其合作伙伴据此展示个性化广告。

你可以通过 Google 我的广告中心管理个性化广告，也可以访问 AboutAds 选择页面了解参与广告服务商的退出选项。广告数据处理详情见 Google 广告政策说明。面向需要取得同意的地区启用广告时，还应提供适用的同意管理和撤回入口。

外部链接与公开反馈

本站链接到 GitHub 和其他外部网站。点击链接后，相关网站按照各自的隐私政策处理访问和提交的信息。GitHub Issues 中的反馈是公开的，请勿提交私人文稿、个人信息或受版权保护的完整文件。

联系与更新

关于这份说明或数据处理的问题，请通过联系与反馈中的 GitHub 渠道联系维护者。如果托管方式或广告配置发生变化，我们会更新本页和更新日期。
