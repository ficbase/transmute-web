# AdSense 内容与体验修正 · 2026-10-19

用户提供的 AdSense 网站详情显示 `epubloom.com` 的问题是 **Low value content**，所有权验证已通过，ads.txt 为 **Authorized**。后台要求独特实用价值、持续维护及真实用户兴趣；这不是连接代码或 ads.txt 缺失的问题。邮箱中的通用拒绝通知没有这些具体细节，判断依据是本次后台截图。

## 此次可验证的改动

- 首页增加一键载入 TXT 和 EPUB 公开示例，访客不需要自行准备或下载后重新选择文件，就能体验现有阅读、转换和下载流程。
- 当前有文件时停用试用按钮；异步示例请求不会覆盖在等待期间选择的稿件。下载失败可重试，不清除用户文件。
- 首页新增原文节选、实际生成的封面和两章目录对照，可直接下载原始 TXT 与转换后的 EPUB，并说明元数据、可重排版式、正文保留与格式损失。
- 两种语言的 EPUB 由本站同一 WASM 引擎生成；封面直接从 EPUB 中提取。构建脚本检查两章导航及全部非空原文行，CI 重复验证，避免展示虚构的转换结果。
- 指南链接同一套公开样例；关于页面列出有依据的功能变更和公开源码、反馈入口；隐私说明补充载入样例产生的常规请求。
- 修正阅读器首次加载时的 busy 状态，避免上一本书的完成状态在新书仍加载时被辅助技术读取。
- 正式站和 GitHub Pages 预览仍按原有规则分别发布，未修改发布商 ID、所有权验证码或已有 canonical 地址。

## 复审边界

本次更新补强了实际工具体验、可复现的原创示例与公开维护信息，不能代表 Google 已撤销问题。真实、持续的用户兴趣需要运营与使用数据，无法靠增加字数、伪造流量或改几处 HTML 达成。没有最低篇数、字数或固定等待天数的通过承诺。

应在完整验证线上示例后评估复审；本次不替用户勾选“我确认已修复所有问题”，也不把代码发布描述为审核通过。

依据：[AdSense 网站准备要求](https://support.google.com/adsense/answer/7299563)、[低价值或无发布商内容页面的政策](https://support.google.com/publisherpolicies/answer/11112688)。
