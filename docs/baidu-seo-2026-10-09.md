## 网站端准备

- 中文首页为 `https://epubloom.com/zh/`，11 个中文页面提供静态正文、独立中文标题和描述、自引用 canonical，以及直接可抓取的导航与文章链接。
- 英文仍为默认语言；不会向 Baiduspider 投放不同正文或根据 IP 强制跳转。中文入口可从全站语言链接进入。
- 新增 `sitemap-zh.xml` 和 `baidu-urls.txt`，从同一份页面清单生成 11 个中文规范地址，无首页别名、参数地址、重定向地址和重复条目。站点地图为平铺的标准 XML，原有 22 页双语站点地图保留。
- robots 允许所有搜索引擎抓取，并声明两份站点地图。无需另加重复的 Baiduspider 放行规则。
- 每页增加 `applicable-device=pc,mobile`，表达当前已有的响应式布局。
- 实际公开 HTML 验证码保存在 `baidu-site-verification.txt`，后续正式构建自动保留；`BAIDU_SITE_VERIFICATION` 可覆盖。验证码文件不单独发布，预览页面不注入验证标签。

## 平台操作

1. 在站点管理添加 `https://epubloom.com/`，使用正式 HTTPS 主站地址。
2. 选择与 TXT/EPUB 转换工具实际用途一致的分类。选择 HTML 标签验证，把实际 content 值交给构建脚本后发布。
3. 验证成功后保留项目中的公开验证码，正式构建会自动读取。
4. 在普通收录提交 `https://epubloom.com/sitemap-zh.xml`；若当前账号没有 sitemap 权限，使用界面允许的手动提交方式，网址来自 `https://epubloom.com/baidu-urls.txt`。
5. 使用抓取诊断查看真实抓取结果，之后依据索引量、搜索词和点击数据维护中文内容。配额和功能以实际账号界面为准。
