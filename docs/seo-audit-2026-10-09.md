## 技术改动

- 静态 HTML 直接包含对应语言的正文、独立 title、description 和单一 H1，无需执行 JavaScript 才能阅读。
- 每页自引用 canonical；英文、简体中文、x-default 双向 hreflang；XML 站点地图列出 22 个规范地址及其语言版本。
- 明确的语言网址优先于浏览器保存的偏好，避免英文网址在加载后变成中文地址。
- 可见面包屑、文章内目录、EpuBloom 署名；BreadcrumbList、Article、WebPage 数据与正文一致，没有虚构评分、作者身份或更新时间。
- 1200 × 630 PNG 分享卡、Open Graph、Twitter 大图信息与图片预览设置。
- GitHub Pages 预览使用 noindex，正式服务器保持可索引。允许 Google 抓取预览页面以读取 noindex。
- HTTP 与 www 统一永久跳转到正式 HTTPS 域名；`/index.html`、`/zh/index.html` 永久跳转到对应目录，保留查询参数。
- 不存在的网址返回真实 404；隐藏文件仍受保护；CSS、JS、WASM 开启 gzip 和一小时缓存，HTML 要求重新验证缓存。
- GitHub 仓库主页链接指向正式网站。

服务器配置见 [`deploy/nginx/epubloom.conf`](../deploy/nginx/epubloom.conf)。本次替换前已备份，语法检查和发布后的状态检查均通过；未改变其他站点和证书路径。
